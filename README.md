# Коврик / Kovrick

Фронтенд-прототип соцсети «Коврик». Визуальный скелет без бэкенда: все посты, комментарии и профили — захардкоженные моки. Сделан для того, чтобы посмотреть и потыкать UI с телефона, планшета и десктопа.

Название переключается по языку браузера (`navigator.language`): `ru` → «Коврик», всё остальное → «Kovrick».

## Стек

- React + Vite (статическая сборка под GitHub Pages)
- `react-router-dom` (HashRouter — без серверных rewrite-правил)
- Чистый CSS, без UI-фреймворков
- Google Fonts: Climate Crisis (лого), Dela Gothic One (кнопки/интерактив), Unbounded (контент), JetBrains Mono (таймстемпы/мета)

## Экраны

- Регистрация (`/welcome`) — показывается при первом заходе; анкета (имя, ник, био, город) или вход демо-профилем «Лена Волна»
- Лента (`/`) — карточки постов и репостов, лайк, репост/цитата, счётчики, пример NSFW-карточки с блюром
- Пост (`/post/:id`) — пост + комментарии + локальная форма добавления комментария
- Профиль (`/profile/:username`) — аватар, био, статистика, сетка своих постов и репостов
- Редактирование профиля (`/settings/profile`) — смена имени/ника/био/города, выход
- Поиск (`/search`) — поиск людей и постов, популярные хэштеги без запроса
- Тег (`/tag/:tag`) — лента постов с конкретным хэштегом
- Новый пост / цитата — модальное окно поверх ленты (кнопка «+» в навигации), публикация закрывает модалку и показывает пост в ленте

Хэштеги (`#тег`) и упоминания (`@ник`) в тексте постов и комментариев кликабельны.

## Хранение состояния

Всё состояние живёт в памяти (`StoreContext`) и обнуляется при перезагрузке страницы — **кроме** сессии текущего пользователя: `{ currentUsername, profile }` сохраняется в `localStorage` (`kovrick:session`), поэтому после регистрации или смены ника обновление страницы не выкидывает обратно на экран регистрации. Посты, лайки, репосты и комментарии не сохраняются.


```bash

```

## Деплой

Пуш в `main` триггерит `.github/workflows/deploy.yml`, который собирает проект и публикует `dist/` на GitHub Pages. В настройках репозитория (Settings → Pages) источник должен быть выставлен на **GitHub Actions**.
